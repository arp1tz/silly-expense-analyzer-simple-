# Expense Analyzer (v1 - Basic CLI Version)

A simple command-line based expense tracker built using Python.

FEATURES FOR NOW will add later
* Add expenses with amount and category
* Calculate total expenses
* Category-wise breakdown of spending
* Basic spending warning system

#Tech for now
* Python
* Lists and Dictionaries
* Basic CLI (Command Line Interface)

#Working 

The program takes user input for expenses and stores them in a list.
It then calculates:

* Total spending
* Category-wise totals

##Limitations (Current Version)

* Data is not saved (resets after program ends)
* No menu system (linear flow)
* No edit/delete functionality
